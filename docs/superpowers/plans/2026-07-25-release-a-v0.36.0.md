# Release A (v0.36.0) — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer les items 0/1/2/3 de la spec `2026-07-25-identite-conversation-volumes-alias-notifs-design.md` : un résolveur de libellé unique + ré-étiquetage en place, les volumes par pair persistés, le renommage local, et son + pastilles de non-lu — sans toucher une ligne de Rust.

**Architecture:** Tout se passe dans `ui/src/*.ts` + `ui/index.html`. `state.ts` gagne le résolveur (`memberName` alias-first), trois nouvelles clés `localStorage` et les compteurs de non-lu ; `dom.ts` gagne `clampLabel` et `playPing`. Les libellés d'auteur déjà affichés sont ré-étiquetés **en place** via un attribut `data-from`, jamais par un re-rendu du journal (un re-rendu détruirait les images du chat).

**Tech Stack:** TypeScript (ES modules, `tsc` → `ui/js`), pas de framework, pas de bundler. Tauri 2 côté hôte, non modifié par ce lot.

## Global Constraints

- **Aucune modification de `src-tauri/`** — ni Rust, ni `Cargo.toml`, ni `tauri.conf.json` (sauf le bump de version en toute dernière tâche), ni `capabilities/default.json`, ni le CSP.
- **Aucun nouveau tag `KIND`/`GKIND`, aucune nouvelle commande Tauri, aucun nouvel événement.** Trois déclarations de **type** seulement.
- **Après CHAQUE édition d'un `.ts` → `npm run build`**, et le `ui/js/*.js` compilé est committé avec le `.ts`. Le build Tauri sert `ui/js` tel quel.
- **Contrat DOM** : aucun `id` ni classe existants renommés. Ajouts seulement, plus la substitution locale libellé→`<input>` de la tâche 8.
- **Pas de harnais de test TS dans ce projet.** Le cycle de test de chaque tâche est : (1) `npm run build` compile sans erreur, (2) la vérification manuelle nommée dans la tâche. Ne pas inventer de framework de test.
- **Jamais transformer un signal best-effort en précondition d'affichage** (leçon #1) : le re-push de gain et la résolution de libellé sont des surcouches. Un échec ⇒ comportement actuel, pas de blocage.
- **Ne jamais appeler `renderGroupMsgs()` pour rafraîchir un libellé** : il fait `clearImgBlobs` + `innerHTML = ""` et ne rejoue que le texte ⇒ toutes les images affichées disparaissent.
- Commandes depuis `ghost-link-rust/`. Build TS : `npm run build`.

```ts
export const ALIASKEY = "ghostlink_aliases"; // code → surnom LOCAL choisi par moi
export const GAINKEY = "ghostlink_gains"; // code → gain voix en % (0..200)
export const SGAINKEY = "ghostlink_sgains"; // code → gain du son d'écran en % (0..200)
/** Plafond du carnet de surnoms. Les surnoms NE sont PAS élagués à la suppression d'un
 *  ami ni à un kick (c'est tout leur intérêt : survivre à ces événements) — seul ce
 *  plafond borne la croissance, comme les 64 de ghostlink_pending_freq_out. */
const ALIAS_MAX = 256;

export function loadAliases(): Record<string, string> {
  try {
    return (JSON.parse(localStorage.getItem(ALIASKEY) || "{}") as Record<string, string>) || {};
  } catch {
    return {};
  }
}
/** Pose ou retire (name vide) un surnom local. Refuse un code non permanent. */
export function setAlias(code: string, name: string): void {
  const key = persistKey(code);
  if (!key) return;
  const m = loadAliases();
  const v = clampLabel(name);
  if (v) m[key] = v;
  else delete m[key];
  const keys = Object.keys(m);
  if (keys.length > ALIAS_MAX) for (const k of keys.slice(0, keys.length - ALIAS_MAX)) delete m[k];
  localStorage.setItem(ALIASKEY, JSON.stringify(m));
}

/** Lit une carte code → pourcentage, en bornant à 0..200. `set_gain` côté Rust n'a AUCUN
 *  clamp (contrairement à set_screen_gain) et localStorage est éditable : une valeur
 *  aberrante irait droit dans la somme du mixeur. */
function loadPctMap(key: string): Record<string, number> {
  const out: Record<string, number> = {};
  try {
    const m = (JSON.parse(localStorage.getItem(key) || "{}") as Record<string, unknown>) || {};
    for (const c of Object.keys(m)) {
      const n = Number(m[c]);
      if (Number.isFinite(n)) out[c] = Math.max(0, Math.min(200, Math.round(n)));
    }
  } catch {
    /* carte illisible : on repart à vide */
  }
  return out;
}
/** Écrit une carte de gains, élaguée aux pairs qu'on peut encore appeler (amis ∪ membres
 *  de groupes). Contrairement aux surnoms, un gain n'a de sens que pour ces gens-là. */
function savePctMap(key: string, m: Record<string, number>): void {
  const keep = new Set<string>(loadFriends().map((f) => f.code));
  for (const g of loadGroups()) for (const c of g.members) keep.add(c);
  const out: Record<string, number> = {};
  for (const c of Object.keys(m)) if (keep.has(c) && m[c] !== 100) out[c] = m[c];
  localStorage.setItem(key, JSON.stringify(out));
}
export function loadGains(): Record<string, number> {
  return loadPctMap(GAINKEY);
}
export function loadSGains(): Record<string, number> {
  return loadPctMap(SGAINKEY);
}
export function saveGains(): void {
  savePctMap(GAINKEY, S.groupGains);
}
export function saveSGains(): void {
  savePctMap(SGAINKEY, S.screenGains);
}
export function resetGains(): void {
  S.groupGains = {};
  S.screenGains = {};
  localStorage.removeItem(GAINKEY);
  localStorage.removeItem(SGAINKEY);
}
```

- [ ] **Step 5: Remplacer `memberName` et ajouter `persistKey` + `ensureFpLabel`**

Remplacer la fonction existante :

```ts
/** Un code n'est persistable que s'il est PERMANENT. Les codes de groupe et d'ami le
 *  sont par construction (le mesh dial via net.perm) ; S.currentPeer peut être éphémère.
 *  Garde défensive : sur les surfaces de ce lot elle ne retourne jamais null. */
export function persistKey(code: string): string | null {
  if (!code) return null;
  if (loadFriends().some((f) => f.code === code)) return code;
  if (loadGroups().some((g) => g.members.includes(code))) return code;
  return null;
}

/** LE résolveur de libellé d'un pair. Échelle, « vide ⇒ on descend d'un cran » :
 *    surnom local → nom d'ami → nom DÉCLARÉ (borné) → empreinte → code court
 *  Le nom déclaré reste un échelon et n'est jamais remplacé par le code : les membres
 *  arrivés par convergence de roster n'ont PAS de nom local, et les afficher en
 *  hexadécimal serait une régression par rapport à aujourd'hui. L'appelant marque ce
 *  cas avec la classe .unverified (cf. isDeclaredLabel). */
export function memberName(code: string, declared?: string): string {
  const al = loadAliases()[code];
  if (al) return al;
  const f = loadFriends().find((x) => x.code === code);
  if (f && f.name) return f.name;
  const d = clampLabel(declared);
  if (d) return d;
  const fp = S.fpCache[code];
  if (fp) return fp;
  return shortId(code);
}
/** Vrai si le libellé affiché vient du nom AUTO-DÉCLARÉ du pair (donc non vérifiable).
 *  Pilote la classe .unverified — sans ce marquage, l'utilisateur réapprend à faire
 *  confiance aux noms, et le surnom perd sa valeur anti-usurpation. */
export function isDeclaredLabel(code: string, declared?: string): boolean {
  if (loadAliases()[code]) return false;
  const f = loadFriends().find((x) => x.code === code);
  if (f && f.name) return false;
  return !!clampLabel(declared);
}

// Empreintes en vol / échouées : ensureFpLabel est appelée DEPUIS le rendu et
// redéclenche un rendu ; sans ces deux gardes un invoke qui échoue reboucle à l'infini.
const fpInFlight = new Set<string>();
const fpFailed = new Set<string>();
/** Remplit S.fpCache[code] puis rappelle `after` pour ré-afficher. Ne résout rien
 *  elle-même. No-op si un surnom/ami existe, si le cache est déjà rempli, si un appel
 *  est en vol, ou si un appel précédent a échoué. */
export async function ensureFpLabel(code: string, after?: () => void): Promise<void> {
  if (!code || S.fpCache[code] || fpInFlight.has(code) || fpFailed.has(code)) return;
  if (loadAliases()[code]) return;
  if (loadFriends().some((x) => x.code === code && x.name)) return;
  fpInFlight.add(code);
  try {
    S.fpCache[code] = await invoke("fingerprint", { code });
    if (after) after();
  } catch {
    fpFailed.add(code); // cache négatif : ne pas re-tenter en boucle
  } finally {
    fpInFlight.delete(code);
  }
}
```

```ts
      actx = new C();
    } catch {
      return null;
    }
  }
  if (actx.state === "suspended") void actx.resume().catch(() => {});
  return actx;
}
/** Joue un bip court. Limité à 1 par 2 s PAR TIMBRE (et non globalement : un limiteur
 *  partagé ferait taire un appel entrant arrivé juste après un ping de message). */
export function playPing(kind: PingKind): void {
  if (localStorage.getItem("ghostlink_sound") === "0") return;
  const now = Date.now();
  if (now - (lastPing[kind] || 0) < 2000) return;
  lastPing[kind] = now;
  const a = ctx();
  if (!a) return;
  const freq = kind === "call" ? 880 : kind === "req" ? 620 : 740;
  const dur = kind === "call" ? 0.22 : 0.12;
  try {
    const o = a.createOscillator();
    const g = a.createGain();
    o.type = "sine";
    o.frequency.value = freq;
    g.gain.setValueAtTime(0, a.currentTime);
    g.gain.linearRampToValueAtTime(0.14, a.currentTime + 0.01);
    g.gain.exponentialRampToValueAtTime(0.0001, a.currentTime + dur);
    o.connect(g);
    g.connect(a.destination);
    o.start();
    o.stop(a.currentTime + dur + 0.02);
  } catch {
    /* pas de son : jamais bloquant */
  }
}
```
